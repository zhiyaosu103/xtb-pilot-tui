# xTB-Pilot 设计决策与技术细节归档

本文档记录 xTB-Pilot 在架构设计、异常恢复、环境兼容性方面的关键考量及历史验证记录。

---

## 1. 架构与容错设计决策

### 1.1 进程解耦与生命周期

- **Daemon 独立存活**：TUI 仅作为前台观察端。`xtbp-tui` 通过 UDS 与后台 `xtbp-daemon` 通信。Daemon 通过 `setsid` 脱离控制终端运行，确保用户关闭终端会话或网络断开时，长时间运行的高通量任务不受影响。
- **单调时钟约束**：运行时计时与超时管理全部基于单调时钟（Monotonic Clock），避免因宿主系统（如 Windows 睡眠/唤醒）引发的时间跳变问题。

### 1.2 存储与宕机恢复（Crash Resilience）

- **目录自洽（Self-contained Workspace）**：每个任务严格采用独立子目录（`input/`、`work/`、`output/`）。任务启动前生成 `cmd.txt`，包含子进程拉起时的完整环境变量注入（如 `OMP_NUM_THREADS`、`ulimit -s unlimited`）与命令行参数。若 Daemon 异常崩溃，研究人员可直接进入目录排查或单步重跑。
- **SQLite WAL 模式与状态收敛**：数据库使用 Write-Ahead Logging 机制。当系统遭遇非正常终止（如 `kill -9`）并重启后，未完成的 `Running` 或 `Queued` 任务会在启动扫描时被统一标记为 `interrupted`，允许用户手动重试或安全取消，防止任务处于假死悬挂态。
- **文件系统限制校验**：Daemon 启动时会硬校验工作路径。若指定路径位于 `/mnt/c/`（WSL 9P 协议文件系统挂载点），程序将主动拒绝启动。原因在于 9P 文件系统的 IO 延迟与文件锁机制无法承受大规模量化计算的高频临时文件读写。

### 1.3 输出解析的降级策略（Graceful Degradation）

- 解析器优先消费机器可读的格式（如 xtb 6.7.1 的 `--json` 产生的 `xtbout.json`、CREST 的能量列表、stda 标准跃迁表）。
- **非致命解析异常**：由于量化软件版本输出差异，若输出文件存在但解析字段不全，系统不会将整个计算任务标为失败，而是标记为 `parse_degraded` 并保留全部原始文件与日志，TUI 上显示警告图标提示人工复核。
- 所有产物均默认附带 `method_tier: screening` 属性，标明半经验级别筛选定位。

## 2. 组件探测与注册机制 (InstanceRegistry)

Daemon 启动时按以下优先级遍历环境并构建 `registry.toml`（位于 `~/.local/share/xtbpilot/`）：

1. `PATH` 环境变量
2. Conda 激活环境路径
3. `~/opt/<tool_name>-*/bin/` 预编译路径

**针对缺少 Conda-Forge 包的组件回退机制：**

- `xtb4stda` 与 `stda`：若无包管理器支持，回退至 `~/opt/xtb4stda-1.0` 目录下的 grimme-lab 二进制文件，并强制检查当前用户环境或 `XTB4STDAHOME` 下是否存在参数文件 `.param_stda1.xtb` 与 `.param_stda2.xtb`。
- 版本自省失败处理：部分工具（如仅输出 banner 的老版本 `xtb4stda`）自省版本号失败时，系统赋予 `0.0.0` 占位版本以允许调度，而非直接报错阻断。

## 4. 关键缺陷复盘（测试中发现并修复的边界问题）

在集成测试阶段（尤其是 PTY 终端仿真与高并发压测下），系统修复了以下关键隐患：

1. **键盘事件阻塞 Tokio Worker**：在 TUI 交互循环中，原有的终端事件同步读取阻塞了异步运行时线程，导致退出时 `Runtime::drop` 死锁；后改为单独的事件监听线程与通道解耦。
2. **过滤态下的索引映射错位**：当在 TUI 中使用 `/` 过滤任务列表时，选中的视觉索引与全局数据索引未做投影转换，曾导致 `Space` 查看详情或 `c` 取消操作作用于错误的任务。
3. **工作流子步骤取消级联**：原任务视图混合展示了复合工作流的主任务与 DAG 子任务。用户若单独对子任务执行 `c`（取消），会导致整条工作流异常失败；现已明确主子任务从属关系，UI 限制仅允许取消根工作流任务。
4. **已知未解决边界**：
   - 崩溃任务暂不支持基于 `xtbopt.coord` 的断点自动续算，当前仅做可解释的状态中断标记。
   - 配置页面当前仅支持只读查看，热重载机制保留在后续规划中。
